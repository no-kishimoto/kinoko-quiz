# Gradio版の動作確認

完成対象は、きのこ30種類・しょくぶつ40種類・こんちゅう29種類・きょうりゅう10種類。ゲームの説明は `SPEC.md`、起動方法は `../README.md` を参照する。

## 自動テスト

リポジトリのルートから実行する。

```bash
.venv/bin/python -m pytest -q
```

`tests/test_ui_flow.py` は、正誤に対応する音声、さがしの正解後の追加クリック、図鑑画像からの詳細表示、タイトルへ戻るときの状態リセットを検証する。

## PCブラウザでの確認項目

4分野それぞれで、以下を確認する。画面更新が終わってから次の操作を行う。

- クイズ：5問と10問を選べる。回答でカラー画像・正誤・解説・効果音が出て、次の問題へ進める。結果画面の問題数と正解数が合う。
- たしざん・ひきざん：10問で結果画面へ進める。1〜4問は絵あり、5〜7問は数字のみ、8〜10問は漢数字と絵あり。正誤の音が区別できる。
- さがし：外れたクリックでは音を鳴らさず、もう一度探せる。正解後に画像をもう一度クリックしても「つぎの もんだい」が残り、5問で結果画面へ進める。
- ずかん：画像と名前の両方から詳細を開ける。詳細から戻ると元のページを表示する。最初と最後のページでは、範囲外へ進むボタンが無効になる。
- 戻る操作：クイズの問題数選択、クイズ中、計算中、さがし、図鑑、結果からタイトルへ戻れる。分野を選び直しても、前の分野の問題が混ざらない。
- 表示：PCの画面高が低い場合もスクロールして解説と操作ボタンに到達できる。

効果音はブラウザの音声再生設定にも影響される。実際に遊ぶPCで音量と再生を確認する。
