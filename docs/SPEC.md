# きのこ教育ゲーム 仕様書

- 仕様バージョン: v1.0
- 現在の工程: Gradio版の4分野の動作検証・完成に向けた修正
- 確定範囲: Phase 0-1 から Phase 0-12
- 開発方針: GitHubベースでゼロから再構築する

## 1. この文書の目的

きのこ教育ゲームを再構築する際の確定仕様を管理する。

確定していない内容は実装者の判断で補完しない。各項目を順番に確認し、合意後にこの文書の「確定仕様」へ追加する。

## 2. Phase 0-1 確定仕様

### 2.1 タイトル画面

タイトル画面には、ゲーム名として「きのこクイズ」を表示する。

タイトル画面には次の4つの入口を設ける。

1. 「クイズで あそぶ」
2. 「たしざんで あそぶ」
3. 「きのこ さがし」
4. 「きのこ ずかん を みる」

表記は上記のとおりとする。

### 2.2 クイズの問題数

クイズを始める際、次のいずれかを選択できる。

- 5もん
- 10もん

### 2.3 きのこ図鑑の一覧

- 1ページに表示するきのこは3つとする。
- 配置は3列×1段とする。
- 総ページ数は、登録されているきのこの数から自動計算する。

## 3. Phase 0-2 確定仕様

### 3.1 対象ユーザー

- 4〜5歳の子どもを主な対象とする。
- ユーザーの息子が遊ぶことを想定して設計する。

### 3.2 対応端末

- 初期版はPCに対応する。
- スマートフォンおよびタブレットへの対応は、現時点では未確定とする。

## 4. Phase 0-3 確定仕様

### 4.1 出題形式

- 回答前は、きのこのシルエット画像を問題として表示する。
- 回答前のシルエット画像では、きのこごとに指定した1か所を円形に抜き、その範囲だけをカラーで表示する。
- 円形にカラー表示する位置は、そのきのこを見分ける手掛かりとなる部分に設定する。
- 表示された画像のきのこの名前を、3つの選択肢から選ぶ形式とする。
- 回答後は、シルエット画像を同じきのこのカラー画像へ切り替える。

### 4.2 ヒント

各問題では、次の情報をヒントとして提供する。

- 有毒または無毒
- 形態的特徴を表す短い一言

ヒントは問題画面に最初から表示する。ヒントを表示するための追加操作は必要としない。

## 5. Phase 0-4 確定仕様

### 5.1 回答後の表示

ユーザーが選択肢を選んだ後、次の内容を表示する。

- 回答が正解か不正解かの判定
- 正しいきのこの名前
- そのきのこについての解説

正誤判定は、大きな文字で次のように表示する。

- 正解時: 「せいかい！」
- 不正解時: 「せいかいは ○○」

不正解時の `○○` には、正しいきのこの名前を入れる。

解説には、次の3項目を掲載する。

- どこに生えるか
- 見た目の特徴
- 有毒／無毒と注意点

各項目は、4〜5歳の子どもが理解しやすい短い言葉で表現する。

ゲーム全体に共通する独立した安全注意書きは表示しない。各きのこの注意点は、上記の「有毒／無毒と注意点」に含める。

### 5.2 次の問題への進み方

- 回答後に「つぎへ」ボタンを表示する。
- ユーザーが「つぎへ」ボタンを押すと、次の問題へ進む。
- 回答後、次の問題へ自動では移動しない。

### 5.3 出題順と重複

- クイズを開始するたびに、登録されているきのこから問題をランダムに選ぶ。
- 1回のクイズ内では、同じきのこを重複して出題しない。

### 5.4 進行状況の表示

- 問題画面には、現在の問題番号と全問題数を表示する。
- 表示例は「もんだい 2 / 5」とする。
- 最終的な文字の大きさ、色、配置は現時点では未確定とする。
- クイズ中には正解数を表示しない。正解数は、すべての問題が終わった後の結果画面だけに表示する。

## 6. Phase 0-5 確定仕様

### 6.1 結果画面

すべての問題への回答が終わった後、結果画面を表示する。

結果画面には、次の内容を表示する。

- 全問題数
- 正解数

全問正解した場合は、次の特別メッセージを表示する。

> これで きみも きのこ はかせだ！！

正答率は表示しない。全問正解時を除き、正解数に応じた評価や特別メッセージは表示しない。

### 6.2 結果画面の操作

- 結果画面には「タイトルへ もどる」ボタンを表示する。
- ボタンを押すとタイトル画面へ戻る。
- 「もういちど あそぶ」ボタンは設けない。

## 7. Phase 0-6 確定仕様

### 7.1 図鑑一覧から詳細画面への移動

- 図鑑一覧に表示されたきのこをクリックできるようにする。
- きのこをクリックすると、選択したきのこの詳細画面を開く。

### 7.2 詳細画面の掲載情報

図鑑の詳細画面には、次の情報を掲載する。

- きのこの名前
- カラー画像
- 生える場所
- 生える季節
- 大きさ
- 色
- 傘・ひだ・柄などの特徴
- 有毒／無毒
- 似ているきのこ
- 食べ方（食用のきのこの場合）
- 豆知識

文章は、4〜5歳の子どもにも分かりやすい表現を基本とする。

### 7.3 詳細画面の操作

- 詳細画面には「ずかんへ もどる」ボタンを表示する。
- ボタンを押すと、その詳細画面を開く前に表示していた図鑑一覧ページへ戻る。

### 7.4 図鑑一覧のページ移動

- 図鑑一覧に「まえへ」ボタンを表示する。
- 図鑑一覧に「つぎへ」ボタンを表示する。
- 各ボタンを押すと、前または次の一覧ページへ移動する。
- 先頭ページでは「まえへ」ボタンを押せない状態で表示する。
- 最終ページでは「つぎへ」ボタンを押せない状態で表示する。
- 図鑑一覧には、現在のページ番号と総ページ数を表示する。
- 表示例は「1 / 4」とする。
- 総ページ数は、登録されているきのこの数から自動計算する。

### 7.5 タイトル画面へ戻る操作

- 図鑑一覧には「タイトルへ もどる」ボタンを表示する。
- ボタンを押すとタイトル画面へ戻る。

## 11. Phase 0-10 確定仕様

### 11.1 ゲーム画面で使用する文字

- ゲーム画面内の文章、きのこの名前、ボタンおよびラベルには、ひらがなとカタカナを使用する。
- ゲーム画面内では漢字を使用しない。ただし、計算ゲームの8〜10問目の漢数字は例外とする。
- 本仕様書やソースコードなど、ユーザーに表示しない開発資料はこの制限の対象外とする。
- ゲーム画面では算用数字と記号を使用できる。
- 問題数やページ番号には、`5もん` や `2 / 5` のような表記を使用できる。

### 11.2 文字と操作ボタン

- 4〜5歳の子どもが見やすい大きな文字を使用する。
- 4〜5歳の子どもがPCで操作しやすい大きなボタンを使用する。
- 誤操作を減らすため、ボタン同士の間隔を広く取る。
- 具体的な文字サイズ、ボタンサイズおよび間隔は、UI設計時に決定する。

### 11.3 配色

- 4〜5歳の子どもが親しみやすい、明るく楽しい配色にする。
- 具体的な色や配色ルールは、UI設計時に決定する。

## 12. Phase 0-11 確定仕様: きのこ探し

- タイトル画面に「きのこ さがし」の入口を設ける。
- 森の背景は4種類用意し、開始するたびにランダムに選ぶ。
- 登録済みの30種類すべてを、探す対象として出題できるようにする。
- 森には、指定されたきのこ1つと、ほかのきのこ2つを小さく表示する。
- 問題画面には「○○を さがせ！」と、探すきのこの名前を表示する。
- 背景をクリックして、指定されたきのこを見つける形式とする。
- 指定されたきのこをクリックした場合は「ピンポン」の効果音を鳴らし、「せいかい！」と表示する。
- 指定以外をクリックした場合は、音を鳴らさず「もういちど さがしてみよう」と表示する。
- 正解後に「つぎの もんだい」ボタンを表示し、次のランダムな問題へ進める。
- 「タイトルへ もどる」ボタンでタイトル画面へ戻れるようにする。

## 13. Phase 0-12 確定仕様: たしざん

- タイトル画面に「たしざんで あそぶ」の入口を設ける。
- くり上がりのない足し算を10問出題する。
- 問題は「○ ＋ ○ ＝ ？」と表示する。
- 1〜4問目は、式の下に左と右の数と同じ数のアイコンを表示する。
- 5〜7問目はアイコンを隠し、数字だけで計算する。
- 8〜10問目はアイコンを表示し、式と選択肢を漢数字にする。この漢数字は、画面の漢字不使用ルールの例外とする。
- 答えは3つの大きなボタンから選ぶ。
- 正解時は「ピンポン」、不正解時は「ブッブー」の効果音を鳴らす。
- 回答後は「つぎへ」ボタンで進み、最後に正解数を表示する。

## 16. きょうりゅうクイズの確定仕様（2026-10-04）

- 子ども向けの分類名は「🦖きょうりゅう」とする。恐竜以外の古生物もこの入口に含め、説明では実際の仲間を伝える。
- 骨のある生き物は骨格標本の画像から名前を当てる。
- 全身の骨がそろっていない種類は、研究資料に基づいて不足部分を補った復元骨格標本を使用する。
- 骨のない生き物は化石標本と復元画像の組み合わせとする。出題時には化石標本を表示する。
- 骨格標本・化石標本・復元画像の背景は透明とする。既存の標本画像もすべて変更対象とする。
- 選択肢は名前の文字3択とする。回答前に復元画像の選択肢を表示しない。
- 回答後は、正誤、正しい名前、特徴、復元画像の順で表示する。
- 「つぎへ」ボタンで次の問題へ進む。
- 画像と説明文はユーザーの確認用に提示し、確認を得てからゲームへ導入する。
- 未確定事項を補完せず、仕様の質問は3つずつまとめて確認する（2026-10-05、ユーザーの希望により一問一答形式から変更）。質問をまとめる指示は、直前に提示した未回答の仕様案への承認とは扱わない。
- 個別確認では、説明文・骨格／化石標本・生前の復元画像を一組として同時に提示する（2026-10-04追記）。説明文だけを先行して順番に確認しない。

### 16.1 追加する種類

既存の10種類に、シーラカンス、アンキロサウルス、パラサウロロフス、サンヨウチュウ、アノマロカリス、オットイア、マンモス、スミロドンを追加する計画とする（計18種類）。2026-10-05に追加8種類の説明文・標本画像・復元画像がすべて承認された。データは候補用ファイルに保存する。同日、探しゲーム用の18種類に組み込む。クイズ・図鑑は既存10種類のままとし、追加8種類の未確認のクイズヒントは使用しない。

### 16.2 画像作成前の確認事項

- 個別の画像と説明文の確認。生成画像は実際の標本写真ではなく、資料を参考にしたイラストとして提示する。
- 既存10種類の標本画像は、背景透過の確認用PNGを `assets/images/kyouryuu/review/transparent/` に作成済み。変更前後を比較する `index.html` と、生成指示・保存先・透過検査の記録 `manifest.json` を同じフォルダに保存する。
- 確認用画像は既存10種類で透過情報を検査済み。ゲームで使用中の元画像は保持し、画像の承認後に差し替える。追加8種類は2026-10-05に画像と説明文が承認済み。既存10種類の復元画像の透過版は引き続き作成・確認対象とする。

### 16.3 確定した画像モデル

- シーラカンス: 青い現生種（Latimeria chalumnae）。ゲーム内の表示名は「シーラカンス」とする。
- サンヨウチュウ: オレノイデス（Olenoides serratus）。ゲーム内の表示名は「サンヨウチュウ」とする。
- マンモス: ケナガマンモス（Mammuthus primigenius）。ゲーム内の表示名は「マンモス」とする。
- スミロドン: スミロドン・ファタリス（Smilodon fatalis）。ゲーム内の表示名は「スミロドン」とする。

### 16.4 説明文の方針

- サンヨウチュウの説明には、体が中央・右・左の3つに分かれた形に名前が由来する旨を短く含める。
- 前後の頭・胴・尾の3区分を名前の由来と説明しない。
- サンヨウチュウの名前の由来を示す一文は「まんなか・みぎ・ひだりの 3つに わかれた かたちから、この なまえが ついたよ。」で確定する。
- 具体的な説明文は確認用の候補データに保存し、ユーザーの確認を得てからゲームへ反映する。

### 16.5 標本画像と説明文の修正確認（2026-10-04）

- ティラノサウルスは後ろ足の付け根が3本に分岐して見える画像を修正し、骨盤の骨と左右2本の脚を見分けやすくする。説明には小さな前足に2本の爪がある特徴を追加する。後ろ足の爪を2本と説明しない。
- プテラノドンは「よくりゅう」、プレシオサウルスとモササウルスは「かいりゅう」という表現の説明文を確認用に提示する。「海竜」は海生爬虫類をまとめた教育上の呼び方で、単一の分類群とは扱わない。シファクティヌスは海竜ではなく魚として説明する。
- 修正説明文は `assets/images/kyouryuu/review/transparent/review-overrides.json` に保存し、確認ページに表示する。承認されるまでゲーム内データと画像は変更しない。
