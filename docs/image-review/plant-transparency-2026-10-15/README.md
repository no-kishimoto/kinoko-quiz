## 今回確認したこと

- 40種類すべてに完全透明の画素があります。完全に不透明なPNGはありません。
- 葉・枝・茎に囲まれた隙間の背景が消されていない画像があります。
- 図鑑とクイズの透明度データは40組すべて一致しており、同じ残り背景がクイズにも引き継がれています。
- 半透明の画素はありません。ただし、これだけでは本体の一部が完全透明になっていないかを判定できません。

### 細部確認が必要なもの

モウセンゴケ：葉の間に不透明な白い面が見えますが、毛や粘液の白い描写と接するため、修正前に範囲を確認する必要があります。

残る14種類は、一覧では大きな残り背景を特定していません。白い本体の保持・細部の欠け・輪郭の品質まで確認済みという意味ではありません。

## 処理方法との関係

既存の背景除去処理は画像の外周につながる白っぽい部分を消す方式です。葉や茎で囲まれた背景には届かないため、今回の残り方と一致します。現在の画像だけでは過去の処理履歴までは断定できません。

既存の画像整合性テストは、内容が空でないこと・図鑑とクイズの透明度が一致すること等を検査するもので、こうした背景の消し残しを検出できません。

`manifest.json` に80枚のSHA-256と検査値を記録しています。一覧作成前後で元画像のハッシュが変わっていないことを検証しました。白っぽい画素の割合は、正当な白い部位も含むため自動合否判定には使いません。
