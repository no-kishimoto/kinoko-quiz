## 目視結果

アリとコオロギの足の間に、不透明な白・灰色の面が残っています。カマキリの前脚の内側、バッタの後脚の内側、カの脚の間にも同様の残り背景が見えます。

スズメバチには逆方向の問題も見つかりました。大きな翅の右下縁がまだらに完全透明になり、欠けて見えています。原寸の翅の淡色域 `(970,224)` は RGBA `(233,229,222,0)`、近傍 `(930,224)` は `(241,233,221,255)` です。自然な半透明ではなく、完全透明の穴です。図鑑とクイズで同じ状態になっています。修正はしていません。

全29種類の一覧を確認しましたが、上記以外の細部まで問題なしと確定するものではありません。白い翅・毛・体の光沢を背景とみなして、一括で消すことは避ける必要があります。

## 検査と保存

図鑑とクイズの透明度データは29組すべて一致しています。58枚のSHA-256を `manifest.json` に保存し、一覧作成前後で元画像のハッシュが変わっていないことを検証しています。不透明で白っぽい画素の割合も記録していますが、正当な白い部位を含むため、自動合否判定には使用しません。

既存の背景除去処理は外周とつながる白っぽい領域を消す方式です。足や体で囲まれた部分が残る今回の状態と一致しますが、現在の画像だけでは過去の処理履歴までは断定できません。
