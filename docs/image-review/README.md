# 生物の画像を確認する一覧

ゲームで使用中の全99種類を、原画・ヒント画像・説明で並べました。ファイルの読み込みや透明部分の検査と、生物としての形態の正しさの確認は別です。この一覧では後者を確認します。

- [きのこ：30種類](KINOKO.md)
- [植物：40種類](SHOKUBUTSU.md)
- [昆虫：29種類](KONCHUU.md)
- [検索・拡大・確認メモ付きの一覧](index.html)（リポジトリをPCへ取得してブラウザで開く）

見る部位の例：きのこは傘・ひだや管孔・柄・つば・つぼ、植物は花・葉の形と付き方・茎・果実、昆虫は頭・触角・翅・脚・体節・性別による違い。

スズムシは前翅の輪郭を要再確認として扱います。前回の修正では丸さを強調しすぎた可能性があります。コオロギと並べ、実物写真を参考に形を確かめてから再修正します。

確認メモは自動でゲームに反映されません。気になる画像は「名前・部位・違い」を伝えてください。
