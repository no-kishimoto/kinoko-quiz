- 初回は「きのこ」のみで動作と使用感を確認する。
- 30種類の既存データ、シルエット画像、カラー画像、正解音をそのまま使用する。画像や説明文は変更しない。
- 不正解音とBGMは使用しない。

- 「つぎへ」は正誤判定の直下。クイズの途中でもタイトルへ戻れる。
- 図鑑は3列1段。「まえへ」「つぎへ」は上、タイトル戻りは下。詳細から元のページへ戻る。
- 足し算・引き算・きのこ探し、他分野はこの初回試作の対象外。
- 起動時は最大化した独立ウインドウで表示する。表示の大きさは画面に合わせて拡大し、縦横比が変わっても余白を含めて配置を調整する。
- 画面は固定座標ではなく、自動配置のコンテナでタイトル・画像・文字・ボタンの領域を分ける。

## 素材の準備

リポジトリのルートで次を実行する。

```sh
.venv/bin/python -B scripts/sync_godot_kinoko.py
```

きのこ用のJSON・画像60枚・正解音だけを `godot/data/` と `godot/assets/` にコピーする。原本は変更しない。生成先はGit管理対象外で、再実行時は一致するファイルを再利用する。

Pythonはこの素材準備だけに使用する。Godotゲームの実行中にPython・Gradio・インターネット接続は必要ない。

## このPCですぐにゲームを開く

Finderで、このフォルダの **`きのこゲームを起動.command` をダブルクリック**する。

ターミナルが開き、その後「きのこクイズ」のウインドウが開く。ゲームを閉じると終了する。初回や素材更新時は読み込みに時間がかかることがある。起動ファイルはネット接続・インストール・ファイル削除を行わない。

このPCでは素材の同期とGodotへのインポートは済んでいる。

## DockのGodotから開く場合

1. DockのGodotを開く。
2. プロジェクトマネージャーの「インポート」を押す。
3. このフォルダの `project.godot` を選択し、インポートして編集する。
4. エディター右上の▶、またはF5（Macの設定によってはfn＋F5）でプロジェクトを実行する。F6は使用しない。

このPCのプロジェクトファイル:

```text
/Users/kishimotonozomi/Documents/Codex/2026-09-01/referenced-chatgpt-conversation-this-is-an/work/kinoko-quiz/godot/project.godot
```

ファイル選択画面で **⌘＋Shift＋G** を押し、このパスを貼り付けると選択しやすい。

次回からは、Godotの一覧の「きのこクイズ」を開き、▶で実行できる。

### 画面サイズ・文字の重なりの修正後

一度、いま実行中のゲームを停止し、起動し直す。Godotのエディターから実行する場合は、エディターも開き直して新しいウインドウ設定を読み込んでからF5で実行する。`きのこゲームを起動.command` からの起動でもよい。

以前の小さな表示は、エディターの固定サイズ埋め込みプレビューによるものだった。プロジェクトを最大化モードに変更したため、通常の独立ウインドウで表示する。[Godotの公式ウインドウ設定](https://docs.godotengine.org/en/stable/classes/class_projectsettings.html#class-projectsettings-property-display-window-size-mode)では、ゲームの埋め込み表示はWindowedモードのみが対象。

文字の重なりは、日本語ラベルの幅が未設定の間に折り返し高さが膨らみ、その大きな領域の中央に文字が描かれることが原因だった。幅を先に設定し、実際の文字の高さに合わせて自動配置するように修正した。タイトル・画像・ボタンは別々の行に分かれ、ヒントや正誤が長くても隣の操作領域に重ならない。

起動ファイルと検証コマンドは[Godotの公式コマンドライン機能](https://docs.godotengine.org/en/stable/tutorials/editor/command_line_tutorial.html)を使用する。
